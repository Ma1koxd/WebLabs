# Библиотека — лабораторные работы 3 и 4

Продолжение лабораторной работы № 2 на Python и JavaScript.

План работы:

1. Лабораторная № 3: PostgreSQL, ORM SQLAlchemy, миграции Alembic,
   тестовые данные, аутентификация и Docker Compose.
2. Лабораторная № 4: отдельный React-клиент для REST API библиотеки.

Слои приложения:

- `domain` — данные книги;
- `application` — сервис и интерфейс репозитория;
- `infrastructure` — реализация хранения;
- `presentation` — HTTP-маршруты;
- `app` — настройка приложения.
